# 斯奈波喬伊 Sniperjoy

> **精準捕捉，專注紀錄——每一格畫面，都有它的靈魂。**

---

## 我們是誰

斯奈波喬伊是一支以台南為根據地的專業影像製作團隊，服務範疇橫跨商業廣告、政府形象影片、品牌紀錄片與活動攝影。

合作客戶包含**勝昌製藥、威技電器、臺南市政府、臺南 400 文化活動**等，並長期承接品牌 TVC 的導演與監製工作。

---

## 服務項目

| 類別 | 內容 |
| :--- | :--- |
| **商業影片** | TVC 廣告、品牌形象片、產品影片 |
| **政府與公部門** | 形象影片、政策宣導、活動紀錄 |
| **紀錄與行銷** | 紀錄片、行銷短片、活動側錄 |
| **平面攝影** | 商業攝影、人像寫真、活動紀錄 |
| **技術支援** | 即時轉播、後期剪輯、後製製作 |

---

## 為什麼選擇我們

我們不只是「按下快門」——從前期規劃、現場執行到後製交付，每個環節都有專人負責，確保最終成品符合你的期待。

高規格設備搭配豐富實戰經驗，無論是低光源活動現場、商業棚拍，還是戶外紀實，我們都能精準到位。
